# Projeto EcoAção 🌿

## Descrição do Projeto
O **EcoAção** é um site institucional acessível e responsivo desenvolvido para apresentar uma empresa sustentável de embalagens biodegradáveis feitas a partir da fibra de mandioca. Este site foi projetado focando na semântica do HTML5 e nas diretrizes de acessibilidade web (WCAG).
